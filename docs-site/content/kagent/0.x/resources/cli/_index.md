Review the kagent CLI commands and learn how to use them effectively.

- [`kagent add-mcp`]({{< link path="resources/cli/kagent-add-mcp/" >}}) - Add an MCP server entry to kagent.yaml
- [`kagent bug-report`]({{< link path="resources/cli/kagent-bug-report/" >}}) - Generate a bug report
- [`kagent build`]({{< link path="resources/cli/kagent-build/" >}}) - Build a Docker images for an agent project
- [`kagent completion`]({{< link path="resources/cli/kagent-completion/" >}}) - Generate the autocompletion script for the specified shell
- [`kagent dashboard`]({{< link path="resources/cli/kagent-dashboard/" >}}) - Open the kagent dashboard
- [`kagent db`]({{< link path="resources/cli/kagent-db/" >}}) - Database operations (migrations, inspection)
- [`kagent deploy`]({{< link path="resources/cli/kagent-deploy/" >}}) - Deploy an agent to Kubernetes
- [`kagent get`]({{< link path="resources/cli/kagent-get/" >}}) - Get a kagent resource
- [`kagent init`]({{< link path="resources/cli/kagent-init/" >}}) - Initialize a new agent project
- [`kagent install`]({{< link path="resources/cli/kagent-install/" >}}) - Install kagent
- [`kagent invoke`]({{< link path="resources/cli/kagent-invoke/" >}}) - Invoke a kagent agent
- [`kagent mcp`]({{< link path="resources/cli/kagent-mcp/" >}}) - MCP (Model Context Protocol) server management
- [`kagent run`]({{< link path="resources/cli/kagent-run/" >}}) - Run agent project locally with docker-compose and launch chat interface
- [`kagent uninstall`]({{< link path="resources/cli/kagent-uninstall/" >}}) - Uninstall kagent
- [`kagent version`]({{< link path="resources/cli/kagent-version/" >}}) - Print the kagent version
