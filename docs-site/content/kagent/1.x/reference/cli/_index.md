Review the kagent CLI commands and learn how to use them effectively.

- [`kagent apply`]({{< link path="reference/cli/kagent-apply" >}}) - Create or update an AgentTemplate
- [`kagent bug-report`]({{< link path="reference/cli/kagent-bug-report" >}}) - Generate a bug report
- [`kagent completion`]({{< link path="reference/cli/kagent-completion" >}}) - Generate the autocompletion script for the specified shell
- [`kagent create`]({{< link path="reference/cli/kagent-create" >}}) - Create a kagent resource
- [`kagent dashboard`]({{< link path="reference/cli/kagent-dashboard" >}}) - Open the kagent dashboard
- [`kagent db`]({{< link path="reference/cli/kagent-db" >}}) - Database operations (migrations, inspection)
- [`kagent delete`]({{< link path="reference/cli/kagent-delete" >}}) - Delete a kagent resource
- [`kagent get`]({{< link path="reference/cli/kagent-get" >}}) - Get a kagent resource
- [`kagent install`]({{< link path="reference/cli/kagent-install" >}}) - Install kagent
- [`kagent invoke`]({{< link path="reference/cli/kagent-invoke" >}}) - Invoke an AgentInstance
- [`kagent mcp`]({{< link path="reference/cli/kagent-mcp" >}}) - MCP (Model Context Protocol) server management
- [`kagent uninstall`]({{< link path="reference/cli/kagent-uninstall" >}}) - Uninstall kagent
- [`kagent version`]({{< link path="reference/cli/kagent-version" >}}) - Print the kagent version
