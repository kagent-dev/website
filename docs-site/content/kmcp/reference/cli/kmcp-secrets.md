Manage secrets for MCP server projects.

```bash
kmcp secrets [flags]
```

**Subcommands:**
- [`kmcp secrets sync`](/docs/kmcp/reference/cli/kmcp-secrets-sync/) - Sync secrets to a Kubernetes environment from a local .env file

**Flags:**
- `-h, --help` - help for secrets

**Global Flags:**
- `-v, --verbose` - verbose output
