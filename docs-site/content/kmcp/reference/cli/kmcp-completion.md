Generate the autocompletion script for kmcp for the specified shell.
See each sub-command's help for details on how to use the generated script.

```bash
kmcp completion [flags]
```

**Subcommands:**
- [`kmcp completion bash`](/docs/kmcp/reference/cli/kmcp-completion-bash/) - Generate the autocompletion script for bash
- [`kmcp completion fish`](/docs/kmcp/reference/cli/kmcp-completion-fish/) - Generate the autocompletion script for fish
- [`kmcp completion powershell`](/docs/kmcp/reference/cli/kmcp-completion-powershell/) - Generate the autocompletion script for powershell
- [`kmcp completion zsh`](/docs/kmcp/reference/cli/kmcp-completion-zsh/) - Generate the autocompletion script for zsh

**Flags:**
- `-h, --help` - help for completion

**Global Flags:**
- `-v, --verbose` - verbose output
