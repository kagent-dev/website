Review the kmcp CLI commands and learn how to use them effectively.

- [`kmcp add-tool`](/docs/kmcp/reference/cli/kmcp-add-tool/) - Add a new MCP tool to your project
- [`kmcp build`](/docs/kmcp/reference/cli/kmcp-build/) - Build MCP server as a Docker image
- [`kmcp completion`](/docs/kmcp/reference/cli/kmcp-completion/) - Generate the autocompletion script for the specified shell
- [`kmcp deploy`](/docs/kmcp/reference/cli/kmcp-deploy/) - Deploy MCP server to Kubernetes
- [`kmcp init`](/docs/kmcp/reference/cli/kmcp-init/) - Initialize a new MCP server project
- [`kmcp install`](/docs/kmcp/reference/cli/kmcp-install/) - Install the KMCP controller on a Kubernetes cluster
- [`kmcp run`](/docs/kmcp/reference/cli/kmcp-run/) - Run MCP server locally
- [`kmcp secrets`](/docs/kmcp/reference/cli/kmcp-secrets/) - Manage project secrets
