{{- /* Renders one h2 section of another page in place, so the text has a single source. The Install page uses it to show the installation guide's "Before you begin" and "Install with CLI" steps without copying them (the two would drift, and they already differ between docs versions). It takes everything between the named `## ` heading and the next `## ` heading (or the end of the page) from the other page's Markdown source, and renders it in THAT page's context, so its shortcodes (link, reuse, tabs) resolve exactly as they do there. The heading line itself is not included. Same-page links in the section (`](#anchor)`) are pointed at the source page, since those anchors do not exist here, except the ones named in `local`. Parameters: - page | path | yes | — | The source page, relative to the current page. - heading | string | yes | — | The h2's text, without the `## ` and without any `{#id}` suffix. Used inside a regular expression: keep it to plain words. - local | string | no | — | Comma-separated anchors that DO exist on the calling page (because it gives its own sections the same ids), so links to them stay on this page. Example: {{< include-section page="installation" heading="Install with CLI" >}} Fails the build if the page or the heading is missing, so a renamed heading is caught instead of silently publishing an empty panel. */ -}} {{- $pagePath := .Get "page" -}} {{- $heading := .Get "heading" -}} {{- $source := .Page.GetPage $pagePath -}} {{- if not $source -}} {{- errorf "include-section: page %q not found, called from %s" $pagePath .Position -}} {{- else -}} {{- $re := printf `(?s)(?:^|\n)## %s[^\n]*\n(.*?)(?:\n## |\z)` $heading -}} {{- $match := findRESubmatch $re $source.RawContent 1 -}} {{- if not $match -}} {{- errorf "include-section: no h2 %q in %s, called from %s" $heading $source.Path .Position -}} {{- else -}} {{- $text := index (index $match 0) 1 -}} {{- /* Shield the anchors that exist on this page, repoint the rest at the source page, then restore the shielded ones. */ -}} {{- $local := split (.Get "local" | default "") "," -}} {{- range $local -}} {{- with strings.TrimSpace . -}} {{- $text = replace $text (printf "](#%s)" .) (printf "](LOCAL-ANCHOR:%s)" .) -}} {{- end -}} {{- end -}} {{- $text = replace $text "](#" (printf "](%s#" $source.RelPermalink) -}} {{- $text = replace $text "](LOCAL-ANCHOR:" "](#" -}} {{- $source.RenderString (dict "display" "block") $text -}} {{- end -}} {{- end -}}
